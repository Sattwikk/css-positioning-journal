# Henry's Gucci Journal — Inclass-02 CSS Positioning

A responsive journal layout demonstrating CSS box model, float-based columns, clearfix, framed images, and media queries.

## Graduate special features
1. Custom color theme using CSS variables and Google Fonts (Roboto).
2. Hover effects and transitions on sidebar items, cards, and images.
3. Additional tablet breakpoint (769–1024px).

## Files
- `index.html` — main page
- `journal_starter.css` — styles
- `knife.jpg`, `cupcake.jpg` — reference images to be downloaded from the instructor's starter resources

## Run
Open `index.html` in a browser. Keep the images in the same folder.

## Validation
Validate the HTML at https://validator.w3.org/ and CSS at https://jigsaw.w3.org/css-validator/ before submitting.
